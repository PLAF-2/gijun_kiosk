# 영화 예매 키오스크

Next.js · React · TypeScript로 만든 한국어 영화관 예매 데모입니다. 가로형 16:9 화면에 맞춘 어두운 남색 터치 UI와 모바일 레이아웃을 제공합니다.

## 실행

```bash
npm install
npm run dev
npm run build
```

개발 화면은 http://localhost:3000 입니다. 빌드 결과는 `out/`에 생성됩니다. GitHub Actions에서는 저장소 이름을 배포 경로로 사용합니다 (`PLAF-2/gijun_kiosk`는 `/gijun_kiosk`).

개발 서버 캐시는 `.next-dev/`, 운영 빌드 캐시는 `.next/`를 사용합니다. 개발 서버 실행 중 빌드를 해도 캐시가 덮어써지지 않습니다.

## 이용 흐름

극장 문 터치 → 포스터 터치 → 지역·극장 선택 → 날짜·상영 시간 → 인원·좌석 → 예매 확인·휴대폰 번호 선택 입력 → 결제 방식 선택 → 결제 안내 → 예매 번호 확인.

좌석을 선택한 뒤 **내 자리 시야 보기**를 누르면 그 좌석의 앞·중간·뒤, 왼쪽·중앙·오른쪽 위치에 맞춘 예상 화면을 볼 수 있습니다. 여러 좌석을 고른 경우 창 안에서 좌석을 바꿔 비교합니다. 행·열·통로 배치에 따른 개략적 표현이며 실제 극장 사진이나 측정값을 사용하지 않아 스크린 크기·높이·단차·시야는 실제와 다를 수 있습니다.

예매 완료 시 **오늘의 주인공 → 관람 영화 → 극장 → 좌석**이 엔딩 크레딧으로 올라온 뒤 포스터와 예매 번호를 담은 티켓이 표시됩니다. **티켓 바로 보기**로 건너뛸 수 있고 취소·처음으로·저장 경고는 연출 중에도 접근할 수 있습니다. 동작 줄이기 설정에서는 바로 티켓을 보여주며 취소된 예약은 크레딧을 재생하지 않습니다.

홈을 채우는 큰 극장 문을 터치하면 약 1초 동안 문이 열리고 뒤쪽 포스터를 0.1초간 보여준 뒤 영화 목록으로 입장합니다. 중앙의 CINEMA 글자는 N과 E 사이에서 양쪽 문과 함께 갈라집니다. 별도 예매 시작 버튼 없이 문 자체가 예매 진입 버튼이며 안내와 조회·취소는 아래에 배치됩니다. **바로 입장**으로 연출을 건너뛰며 동작 줄이기 설정에서는 즉시 이동합니다. 영화를 선택하면 별빛·바다·숲 등 작품별 배경과 버튼·패널·테두리 색감이 함께 바뀝니다. 예약된 좌석과 선택한 좌석의 표시는 구분됩니다.

화면의 별·발자국과 CINEMA 로고를 터치하면 기념 스탬프를 발견합니다. 완료 화면에서는 **나만의 기념 티켓**의 문구와 별빛·바다·숲·노을·벚꽃·필름·네온 7가지 색감을 선택하고 포스터·예매 내용·발견 스탬프를 담은 PNG를 저장할 수 있습니다. 전화번호와 바코드는 이미지에 포함하지 않습니다. 기념 이미지이며 실제 입장권은 아닙니다. 포스터를 불러오지 못하면 텍스트 티켓을 만들고, 취소된 예매의 이미지 저장은 제한합니다.

스탬프와 티켓 꾸미기 선택은 현재 화면에서만 유지되며 새로고침 시 초기화됩니다. **처음으로**를 누르면 스탬프를 초기화합니다. 예매·결제 데이터에는 영향을 주지 않습니다.

- 전국 17개 시·도에 지역명 뒤에 CINEMA를 붙인 시연 극장을 4개씩, 총 68개 제공합니다. 실제 극장 지점이나 실시간 상영 정보가 아닙니다.
- 오늘부터 7일을 선택할 수 있으며, 극장·날짜별 시간표는 영화 러닝타임과 정리 시간을 반영해 생성합니다. 상영관은 62·86·116·150·174석 배치로 구성되고 전체 좌석 수는 고정됩니다. 회차별 예매된 좌석은 다릅니다. 좌석도에는 통로·행·좌석 번호, 화면 맞춤·확대·축소와 스크롤을 제공합니다. 인원은 1–8명입니다.
- 성인 1인 시연 요금은 월–목 14,000원, 금–일 15,000원입니다. CGV 일반 2D 성인 요금을 참고했으며 실제 요금은 지점·시간·상영 조건에 따라 다릅니다.
- 완료 화면에서 바로 취소하거나, 홈의 **예매 조회·취소**에서 예매 번호 또는 등록한 휴대폰 번호로 찾은 뒤 취소할 수 있습니다. 같은 번호의 예매가 여러 건이면 목록에서 선택합니다. 휴대폰 번호는 선택 입력이며 비워 두어도 결제할 수 있습니다. 번호를 입력한 경우에는 010으로 시작하는 11자리 형식을 확인합니다. 번호를 등록하지 않은 예매는 예매 번호로 조회합니다.
- 취소된 예매는 취소 시각부터 1분 후 화면과 로컬 저장소에서 자동 삭제합니다. 좌석은 취소 즉시 해제됩니다. 화면을 닫거나 브라우저가 일시 정지되면 다시 열거나 화면으로 돌아올 때 지난 취소 내역을 정리합니다. 기존 취소 시각 없는 내역은 첫 로드 시각부터 1분으로 처리합니다.
- 결제 수단은 신용·체크카드, 삼성페이, 애플페이, 카카오페이, 네이버페이, 토스페이, 현금입니다. 각 수단의 IC 카드·NFC·QR/바코드·현금 투입 안내 후 **결제 완료**를 누르면 시연용 예매가 생성됩니다. 선택한 수단을 예매 내역에 저장하며 실제 단말기나 결제 API는 연결하지 않습니다.
- 현재 브라우저의 `localStorage` (`cinema-kiosk-bookings-v1`)에 저장합니다. 새로고침 후 조회할 수 있으며 다른 기기와 공유되지 않습니다. 저장 실패 시 안내를 표시합니다.
- 실제 결제·영화관 예약은 발생하지 않습니다. 상영 일정과 영화의 러닝타임·등급은 시연용 데이터입니다.
- 예매 확인 화면에서 경로(만 65세 이상), 장애인 경증·중증, 국가유공자·유족과 대상 동반 인원을 선택해 할인합니다. 일반 2D 기준 경로 7,000원, 우대 5,000원은 [CGV 공식 FAQ](https://cgv.co.kr/csc/frequentlyAskedQuestion)를 참고한 예시입니다. 중증 장애인과 국가유공상이자 1~3급 본인 1명당 동반 1명까지 적용하며 대상 인원이 전체 인원을 초과할 수 없습니다. 증명서를 수집하거나 실제 자격을 인증하지 않습니다.
- CINEMA 자체 체험 쿠폰 `CINEMA3000`, `CINEMA5000`을 입력하거나 버튼으로 적용할 수 있습니다. 예매당 1매를 일반 요금 1인에 적용하고 우대 요금 표에는 중복 적용하지 않습니다. 우대 인원이 전체 인원이 되면 쿠폰은 해제됩니다. 실제 CGV·정부지원·통신사 쿠폰을 확인하는 기능은 아닙니다. 할인 계산과 최종 예매 금액은 동일한 계산 함수를 사용하며 내역은 완료·조회 화면에도 저장됩니다.

결제 수단과 단말기 안내 구성은 [토스플레이스 공식 연동 안내](https://docs.tossplace.com/guide/front-integration/getting-started.html)를 참고했습니다. 실제 CGV 지점의 결제 수단과 동일하다는 의미는 아닙니다.

## 영화와 포스터

제공된 포스터 10장을 `public/posters/`에서 사용합니다.

극장판 치이카와: 인어 섬의 비밀, 나 홀로 집에, 라라랜드, 만약에 우리, 모아나, 오디세이, 오늘 밤, 세계에서 이 사랑이 사라진다 해도, 마루 밑 아리에티, 비긴 어게인, 쥬라기 월드: 새로운 시작.

영화 목록은 `src/lib/cinema/catalog.ts`, 극장·상영관은 `theaters.ts`, 시간표 계산은 `schedule.ts`, 예매·저장은 `src/lib/cinema/`, 화면은 `src/components/cinema/`에서 관리합니다. 영화 추가 시 포스터를 `public/posters/`에 넣고 `catalog.ts`의 `movies`에 정보를 추가하세요.

각 포스터 아래 **영화 정보 · 예고편**을 누르면 예매 화면을 벗어나지 않고 줄거리와 공식 영상 정보를 볼 수 있습니다. **예고편 재생**을 눌렀을 때만 YouTube 플레이어를 불러오며 닫으면 종료합니다. 재생이 제한되면 **YouTube에서 보기**를 이용할 수 있습니다. 영상은 배급사·스튜디오의 공식 티저/예고편이고 API 토큰은 필요하지 않습니다. 영상 공개·네트워크·임베드 허용 상태에 따라 재생에 제한이 있을 수 있습니다. 목록의 모아나는 2026년 실사판, 오늘 밤은 2022년 일본판에 맞춰 연결했습니다.

할인 기준과 계산은 `src/lib/cinema/discounts.ts`, 영화 설명·공식 영상 주소는 `src/lib/cinema/movie-details.ts`에서 관리합니다.

화면에서는 **혜택 적용**이라는 이름으로 **경로·장애인·국가유공자·혜택** 카테고리를 제공합니다. 대상 카드는 최초 선택 시 1명으로 목록에 넣고, 선택된 카드를 다시 누르면 인원이 늘어나지 않습니다. 이후 인원 변경은 아래 **선택한 혜택** 목록의 `− / +`에서만 가능합니다. 여러 우대 대상을 함께 선택하거나 삭제할 수 있으며, 코드로 적용한 혜택은 카테고리를 바꿔도 적용 목록에 남습니다. 우대 인원은 총 예매 인원을 초과할 수 없으며 본인 인원이 줄면 대상 동반 인원도 함께 조정됩니다. 모든 관객에게 적용한 경우 선택한 총 인원을 안내합니다. 완료·조회 화면의 기존 예약 할인 명칭도 표시할 때 혜택으로 바꿉니다.
