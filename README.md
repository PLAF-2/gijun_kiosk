# 영화 예매 키오스크

Next.js · React · TypeScript로 만든 한국어 영화관 예매 데모입니다. 가로형 16:9 화면에 맞춘 어두운 남색 터치 UI와 모바일 레이아웃을 제공합니다.

## 실행

```bash
npm install
npm run dev
npm run build
```

개발 화면은 http://localhost:3000 입니다. 빌드 결과는 `out/`에 생성됩니다. GitHub Actions에서는 저장소 이름을 배포 경로로 사용합니다 (`PLAF-2/gijun_kiosk`는 `/gijun_kiosk`).

## 이용 흐름

예매 시작 → 영화 선택 → 날짜·상영 시간 → 인원·좌석 → 예매 확인 → 데모 결제 완료 → 예매 번호 확인.

- 오늘부터 7일, 하루 4회 상영을 제공합니다. 좌석은 A–D열 × 8석, 인원은 1–8명입니다.
- 성인 1인 시연 요금은 월–목 14,000원, 금–일 15,000원입니다. CGV 일반 2D 성인 요금을 참고했으며 실제 요금은 지점·시간·상영 조건에 따라 다릅니다.
- 완료 화면에서 바로 취소하거나, 홈의 **예매 조회·취소**에서 7자리 예매 번호를 입력해 취소할 수 있습니다. 확인 후 취소되며 좌석이 해제되고 취소 기록은 유지됩니다.
- 현재 브라우저의 `localStorage` (`cinema-kiosk-bookings-v1`)에 저장합니다. 새로고침 후 조회할 수 있으며 다른 기기와 공유되지 않습니다. 저장 실패 시 안내를 표시합니다.
- 실제 결제·영화관 예약은 발생하지 않습니다. 상영 일정과 영화 상세 정보는 시연용 데이터입니다.

## 영화와 포스터

제공된 포스터 10장을 `public/posters/`에서 사용합니다.

극장판 치이카와: 인어 섬의 비밀, 나 홀로 집에, 라라랜드, 만약에 우리, 모아나, 오디세이, 오늘 밤, 세계에서 이 사랑이 사라진다 해도, 마루 밑 아리에티, 비긴 어게인, 쥬라기 월드: 새로운 시작.

영화 목록·일정은 `src/lib/cinema/catalog.ts`, 예매·저장은 `src/lib/cinema/`, 화면은 `src/components/cinema/`에서 관리합니다. 영화 추가 시 포스터를 `public/posters/`에 넣고 `catalog.ts`의 `movies`에 정보를 추가하세요.

검증 기록: `docs/superpowers/cinema-kiosk-verification.md`.
