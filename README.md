# 영화 예매 키오스크

Next.js · React · TypeScript로 만든 한국어 영화관 예매 데모입니다. 가로형 16:9 화면에 맞춘 어두운 남색 터치 UI와 모바일 레이아웃을 제공합니다.

## 실행

```bash
npm install
npm run dev
npm run build
```

개발 화면은 http://localhost:3000 입니다. 빌드 결과는 `out/`에 생성됩니다. GitHub Actions에서는 저장소 이름을 배포 경로로 사용합니다 (`PLAF-2/gijun_kiosk`는 `/gijun_kiosk`).

## 이용 흐름

예매 시작 → 포스터 터치 → 지역·극장 선택 → 날짜·상영 시간 → 인원·좌석 → 예매 확인·휴대폰 번호 입력 → 결제 방식 선택 → 결제 안내 → 예매 번호 확인.

- 전국 17개 시·도에 지역명 뒤에 CINEMA를 붙인 시연 극장을 4개씩, 총 68개 제공합니다. 실제 극장 지점이나 실시간 상영 정보가 아닙니다.
- 오늘부터 7일을 선택할 수 있으며, 극장·날짜별 시간표는 영화 러닝타임과 정리 시간을 반영해 생성합니다. 상영관은 62·86·116·150·174석 배치로 구성되고 전체 좌석 수는 고정됩니다. 회차별 예매된 좌석은 다릅니다. 좌석도에는 통로·행·좌석 번호, 화면 맞춤·확대·축소와 스크롤을 제공합니다. 인원은 1–8명입니다.
- 성인 1인 시연 요금은 월–목 14,000원, 금–일 15,000원입니다. CGV 일반 2D 성인 요금을 참고했으며 실제 요금은 지점·시간·상영 조건에 따라 다릅니다.
- 완료 화면에서 바로 취소하거나, 홈의 **예매 조회·취소**에서 예매 번호 또는 등록한 휴대폰 번호로 찾은 뒤 취소할 수 있습니다. 같은 번호의 예매가 여러 건이면 목록에서 선택합니다. 휴대폰 번호를 등록하지 않은 기존 예매는 예매 번호로 조회합니다.
- 취소된 예매는 취소 시각부터 1분 후 화면과 로컬 저장소에서 자동 삭제합니다. 좌석은 취소 즉시 해제됩니다. 화면을 닫거나 브라우저가 일시 정지되면 다시 열거나 화면으로 돌아올 때 지난 취소 내역을 정리합니다. 기존 취소 시각 없는 내역은 첫 로드 시각부터 1분으로 처리합니다.
- 결제 수단은 신용·체크카드, 삼성페이, 애플페이, 카카오페이, 네이버페이, 토스페이, 현금입니다. 각 수단의 IC 카드·NFC·QR/바코드·현금 투입 안내 후 **결제 완료**를 누르면 시연용 예매가 생성됩니다. 선택한 수단을 예매 내역에 저장하며 실제 단말기나 결제 API는 연결하지 않습니다.
- 현재 브라우저의 `localStorage` (`cinema-kiosk-bookings-v1`)에 저장합니다. 새로고침 후 조회할 수 있으며 다른 기기와 공유되지 않습니다. 저장 실패 시 안내를 표시합니다.
- 실제 결제·영화관 예약은 발생하지 않습니다. 상영 일정과 영화 상세 정보는 시연용 데이터입니다.

결제 수단과 단말기 안내 구성은 [토스플레이스 공식 연동 안내](https://docs.tossplace.com/guide/front-integration/getting-started.html)를 참고했습니다. 실제 CGV 지점의 결제 수단과 동일하다는 의미는 아닙니다.

## 영화와 포스터

제공된 포스터 10장을 `public/posters/`에서 사용합니다.

극장판 치이카와: 인어 섬의 비밀, 나 홀로 집에, 라라랜드, 만약에 우리, 모아나, 오디세이, 오늘 밤, 세계에서 이 사랑이 사라진다 해도, 마루 밑 아리에티, 비긴 어게인, 쥬라기 월드: 새로운 시작.

영화 목록은 `src/lib/cinema/catalog.ts`, 극장·상영관은 `theaters.ts`, 시간표 계산은 `schedule.ts`, 예매·저장은 `src/lib/cinema/`, 화면은 `src/components/cinema/`에서 관리합니다. 영화 추가 시 포스터를 `public/posters/`에 넣고 `catalog.ts`의 `movies`에 정보를 추가하세요.

검증 기록: `docs/superpowers/cinema-kiosk-verification.md`.
