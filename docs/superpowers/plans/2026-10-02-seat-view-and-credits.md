# Seat View and Completion Credits Implementation Plan

**Goal:** 좌석 선택 시 예상 시야를 확인하고, 예매 완료를 엔딩 크레딧과 티켓으로 연출한다.

**Architecture:** 시야 미리보기는 현재 좌석 배치의 행 순서·물리 열·통로를 이용한 개략적 SVG 장면이다. 실제 극장 사진이나 측정값이 아니며 선택 좌석 버튼과 별도 창으로 제공한다. 완료 연출은 예약 스냅샷을 사용하는 독립 컴포넌트이며 건너뛰기·동작 줄이기·취소 상태를 지원한다. 기존 예매/요금/저장 계산은 변경하지 않는다.

**Tech Stack:** React, TypeScript, SVG, native dialog, CSS modules.

- [x] `seat-screen.tsx`: 현재 선택한 좌석과 마지막으로 선택한 좌석을 연결하고 시야 보기 버튼을 제공한다. 열리는 동안 좌석을 추가/삭제하지 않는다.
- [x] `seat-view-dialog.tsx`, `seat-view.module.css`: 선택 좌석 전환, 앞·중간·뒤/좌·중앙·우 위치 정보, 스크린 크기·위치·사다리꼴 기울기가 바뀌는 SVG 예상 시야를 제공한다. 실제와 다를 수 있음을 표시하고 ESC·닫기·포커스 복원을 처리한다.
- [x] `complete-screen.tsx`, `booking-credits.tsx`, `booking-credits.module.css`: 예약 정보로 6–8초 크레딧과 티켓을 연출한다. 바로 보기·동작 줄이기, 타이머 정리, 취소/저장 경고/홈 접근을 유지한다.
- [x] 소스 검토 후 README를 갱신하고 운영용 빌드·개발 서버 HTTP 응답으로 확인한다. 테스트·커밋·푸시는 실행하지 않는다.

## 완료 기록

- 좌석 예상 시야는 선택한 좌석들 사이에서 전환할 수 있으며 실제 시야와 다를 수 있음을 표시했다.
- 완료 크레딧은 7.4초 후 티켓으로 전환하고 건너뛰기·동작 줄이기·취소 상태를 처리했다.
- 소스 검토, 운영용 빌드 종료 코드 0, 개발 페이지 HTTP 200을 확인했다. 브라우저 조작·레이아웃 검사와 자동 테스트는 실행하지 않았다. 커밋·푸시도 하지 않았다.
