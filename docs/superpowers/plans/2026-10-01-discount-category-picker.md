# Discount Category Picker Implementation Plan

**Goal:** 할인 카테고리를 눌러 대상을 추가하고, 추가한 여러 대상의 인원을 한눈에 조절한다.

**Architecture:** `DiscountSelection`을 그대로 사용한다. 카테고리 선택만 UI 상태로 관리하고, 대상 추가·증감·삭제는 기존 `updateBenefitSelection`으로 계산한다. 적용한 쿠폰은 카테고리를 바꿔도 선택 목록에 표시한다.

**Tech Stack:** React, TypeScript, existing global CSS.

- [x] `discount-panel.tsx`: 경로·장애인·국가유공자·쿠폰 카테고리 버튼과 접을 수 있는 세부 선택 영역을 만든다. 카테고리별 기존 대상 ID를 연결한다.
- [x] 선택 영역에서 대상을 1명씩 추가한다. 선택 인원이 0보다 큰 항목만 목록에 표시하며 증감·삭제를 제공한다. 전체 인원 또는 동반 자격 때문에 추가가 막히면 이유를 표시한다.
- [x] 쿠폰 입력은 쿠폰 카테고리에서 열고 적용한 쿠폰은 선택 목록에 계속 표시한다. 기존 예매당 1매·일반 요금 조건을 유지한다.
- [x] `globals.css`: 카테고리 4개, 세부 항목 버튼, 선택 목록을 작은 화면에서도 읽기 쉽게 배치한다. README 이용 설명을 갱신한다.
- [x] 소스 검토와 운영 빌드로 타입·정적 내보내기를 확인한다. 개발 서버 HTTP 응답을 확인한다. 테스트·커밋·푸시는 실행하지 않는다.

## 확인 기록

- `GITHUB_REPOSITORY=PLAF-2/gijun_kiosk` 환경의 `npm run build`가 종료 코드 0으로 완료됐다. 컴파일, 타입 검사와 정적 내보내기를 통과했다.
- 빌드 후 `http://127.0.0.1:3105/`는 HTTP 200으로 응답했다.
- 카테고리별 대상 연결, 중복 대상 추가 시 인원 증가, 0명/삭제 시 목록 제거와 카테고리 버튼 포커스 복원, 동반·총 인원 제한, 쿠폰 유지 경로를 소스로 검토했다.
- 브라우저 클릭·레이아웃 확인과 자동 테스트는 실행하지 않았다. 커밋·푸시도 하지 않았다.
