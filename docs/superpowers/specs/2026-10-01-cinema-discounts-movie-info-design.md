# 예매 할인과 영화 정보

## 요청과 범위

사용자는 장애인·쿠폰 등 할인 항목을 검색해 결제에 넣고, 각 포스터 하단의 링크에서 영화 설명과 YouTube 티저를 볼 수 있도록 요청했다. 기존 10편과 시연 예매 방식은 유지한다. 변경은 로컬에만 두고 푸시하지 않는다.

## 할인

CGV 공식 FAQ의 일반 2D 우대 요금을 참고한다: 경로(만 65세 이상) 7,000원, 장애인·국가유공자 5,000원. 장애인은 경증 본인·중증 본인·중증 동반 1인을 구분한다. 국가유공자는 일반 본인·유족 또는 상이 4~7급과 상이 1~3급 본인·동반 1인을 구분한다. 할인 대상별 인원 합계가 예매 인원을 초과할 수 없으며 동반 인원은 해당 본인 인원을 초과할 수 없다. 실제 신분증·복지카드 확인에 관한 안내만 표시하고 증명서나 번호를 수집하지 않는다.

예매 확인 화면에서 대상 인원과 쿠폰을 적용한다. 잔여 일반 인원은 자동 계산한다. CINEMA3000, CINEMA5000은 자체 체험용 쿠폰이며 예매당 하나를 일반 요금 티켓 1장에 적용한다. 우대 요금 표에는 쿠폰을 중복 적용하지 않는다. 일반 인원이 0이 되면 쿠폰을 해제한다. 실제 CGV 쿠폰을 인증하거나 통신사/카드사 계정을 연결하지 않는다.

할인 계산 함수를 단일 진입점으로 만들고 예매 확인·결제·예매 생성에서 같은 결과를 사용한다. 최종 예매 생성 시 할인 조건을 다시 검증한다. 원래 금액·할인 내역·최종 금액을 예약에 선택적으로 저장해 기존 예약 저장소와 호환하고 완료·조회 화면에 표시한다. 인원·영화·극장·회차 변경 때 할인 선택을 초기화한다.

## 영화 정보

포스터 선택 버튼과 별개로 각 카드 아래 '영화 정보 · 예고편' 링크를 둔다. 링크는 영화 정보 대화상자를 열며 극장 선택으로 이동하지 않는다. 설명은 공식 배급사/스튜디오/공식 예고편을 참고한 자체 요약으로 제공한다. 모아나는 2026 실사판, 오늘 밤은 일본판, 쥬라기 월드는 새로운 시작 등 제공 포스터의 판본을 구분한다.

공식 영상의 검증된 YouTube ID로 플레이어를 연결한다. 영상은 사용자가 재생을 눌렀을 때만 iframe을 만들며 닫으면 재생을 종료한다. 외부 'YouTube에서 보기' 링크도 둔다. 공식 영상이 확인되지 않은 작품은 그 사실을 표시하고 공식 채널/검색 경로를 제공하되 가짜 영상 ID를 넣지 않는다. 재생에는 API 토큰이 필요하지 않으며 네트워크와 영상 공개/임베드 정책에 영향을 받는다.

## 확인

소스 검토, 할인 결과가 예약에 이어지는 흐름 검토, production build와 TypeScript 확인을 수행한다. 요청하지 않은 테스트를 추가하거나 실행하지 않는다. 푸시·커밋·새 작업 생성은 하지 않는다.
